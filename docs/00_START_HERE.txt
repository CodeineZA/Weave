🎯 COMMON QUESTIONS
═══════════════════════════════════════════════════════════════════════════

Q: How do I join a room?
A: Open http://localhost:3000, enter your name, enter the password, click Join.

Q: Where's the password?
A: Check .env file. Default is "friends123" (change before sharing!).

Q: Can I use this over the internet?
A: Yes! Use Cloudflare Tunnel (free) or deploy to VPS. See GETTING_STARTED.md.

Q: Can I run this 24/7?
A: Yes! Use Raspberry Pi or VPS. See RASPBERRY_PI_GUIDE.md.

Q: Does it record conversations?
A: No. No recording by default. All audio is peer-to-peer.

Q: How many people can join?
A: Works great with 8-10 people. Scales to ~20 with good network.

Q: Is it secure?
A: Yes! Audio is encrypted P2P. Server never sees media. Password protected.


💻 SYSTEM REQUIREMENTS
═══════════════════════════════════════════════════════════════════════════

Minimum:
  • Node.js v14+
  • Any modern browser (Chrome, Firefox, Edge, Safari)
  • 256 MB RAM
  • 100 MB disk space

Recommended for 8-10 users:
  • Node.js v18+
  • 1 GB RAM
  • 1+ Mbps per user upload/download
  • Raspberry Pi 4+ (if self-hosting 24/7)


🌍 DEPLOYMENT OPTIONS
═══════════════════════════════════════════════════════════════════════════

1. Local Network (Fastest)
   → Same Wi-Fi, run server, share IP:port
   → 5 minutes setup

2. Cloudflare Tunnel (Free)
   → Expose to public internet, no port forwarding
   → 10 minutes setup
   → See GETTING_STARTED.md

3. Raspberry Pi (24/7 Server)
   → Runs continuously, costs $35-100
   → 30 minutes setup
   → See RASPBERRY_PI_GUIDE.md

4. VPS (Full Control)
   → DigitalOcean, Linode, etc.
   → Optional TURN server for NAT
   → 60 minutes setup
   → See README.md → Deployment
